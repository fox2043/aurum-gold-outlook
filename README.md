# AURUM SIGNAL 静态站

将本目录内容上传到任意静态网站托管服务即可。入口文件为 `index.html`。

## 数据说明

- 页面为非商业研究展示，预测不构成投资建议。
- 支付宝黄金价需以 App 中的具体产品交易页为准；该类对客价不提供公开匿名接口。
- Yahoo Finance 对外设置了浏览器跨域限制，因此稳定链路以 GitHub Actions 每 5 分钟抓取 COMEX 分钟行情并发布快照为主；页面每分钟检查数据、每 5 分钟强制重载快照。浏览器直连仅作为可用时的加速路径，失败时页面显示最近一次成功快照。
- 部署建议：GitHub Pages 适合公开行情直连与快照后备；若需要每项数据都稳定实时（包括新闻、专家观点、国内银行/支付宝对客价），请将 `api/` 代理部署到 Cloudflare Workers、Vercel 或自有服务器，并使用已授权的数据源及密钥。切勿把密钥放进静态前端。
- `data/dashboard.json` 为静态数据快照；`scripts/refresh-cmb-gold.js` 仅更新招行公开 Au99.99 市场行情，不替代支付宝产品价格。
