# AURUM SIGNAL 静态站

将本目录内容上传到任意静态网站托管服务即可。入口文件为 `index.html`。

## 数据说明

- 页面为非商业研究展示，预测不构成投资建议。
- 支付宝黄金价需以 App 中的具体产品交易页为准；该类对客价不提供公开匿名接口。
- 首屏会直连 Yahoo Finance 的 COMEX 分钟行情，并尝试直连招行公开 Au99.99 行情；每 60 秒刷新一次，失败时保留本地快照。浏览器网络策略可能限制部分源，顶部会显示当前连接状态。
- `data/dashboard.json` 为静态数据快照；`scripts/refresh-cmb-gold.js` 仅更新招行公开 Au99.99 市场行情，不替代支付宝产品价格。
