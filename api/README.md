# 实时数据代理接口说明

纯静态站可直接请求部分开放行情源，但不能安全保存密钥，也无法处理所有跨域、登录态或地区限制。

生产部署时，可将下列接口实现为 Cloudflare Worker、Vercel Serverless Function 或自有服务：

- `GET /api/quotes/gold`：返回 COMEX、现货、人民币折算等已授权行情。
- `GET /api/news/gold`：返回带发布日期和原文 URL 的已核验黄金新闻。
- `GET /api/research/gold`：返回每周专家/机构观点，需保留来源、发布日期与原文链接。

要求：服务端缓存 30–60 秒、记录来源更新时间、源不可用时返回最近成功数据和 `stale: true`。任何 API 密钥仅放在服务端环境变量。

支付宝与银行 App 对客买卖价通常属于登录后产品报价；只有在取得平台授权 API 后才能接入，不应抓取用户登录态或伪造实时值。
